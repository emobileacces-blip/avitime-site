Vos testeurs, votre site, votre modération

En 1 min 35 : le parcours Avitime adapté à votre façon de travailler, sans rien changer à votre site.

  1. Dans votre campagne, vous choisissez la commande avec vos codes promo : un code par testeur, ou un seul code pour toute la campagne.
  2. Avitime sélectionne les testeurs selon leur profil et leurs centres d’intérêt. Chacun reçoit son code et le lien de votre fiche produit.
  3. Le testeur commande à 0 € sur votre site : la commande suit votre circuit habituel, jusqu’à votre transporteur.
  4. Vous renvoyez votre fichier des commandes expédiées (n° de commande ou code promo, et n° de suivi) : chaque testeur voit son suivi.
  5. Après au moins 3 jours d’utilisation, le testeur rédige son avis. Avitime le relit, notamment pour écarter toute allégation santé.
  6. Le testeur publie son avis sur votre fiche produit, avec votre module actuel : rien à intégrer sur votre site.
  7. Vous gardez la main : votre modération s’applique, vous pouvez répondre à chaque avis, et vous confirmez en un clic dans votre espace Avitime qu’il est en ligne.

Une question ? Écrivez-nous à contact@avitime.fr : on vous répond rapidement.
