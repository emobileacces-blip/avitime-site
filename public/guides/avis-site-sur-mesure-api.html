Afficher des avis clients vérifiés sur un site sur mesure (Next.js, Lovable, Bolt…) : clé API et étoiles Google

Votre site a été créé avec Lovable, Bolt ou Next.js, ou par un développeur, et il n’affiche encore aucun avis ? Voici comment faire tester vos produits sans module, expédier vous-même les produits physiques, et afficher les avis vérifiés dans vos pages avec une clé API, au format que Google sait lire.

Cyril Quémy, fondateur d’Avitime
Publié le 1er novembre 2026 · lecture 9 min

Partager :WhatsAppLinkedInFacebookX

L’essentiel : votre site n’est ni sur PrestaShop, ni sur WooCommerce, ni sur Shopify ? Créé avec Lovable, Bolt ou Next.js, par un développeur, ou sur Webflow, Wix, Kajabi : vous pouvez quand même faire tester vos produits, physiques ou numériques, et afficher les avis vérifiés. Sans développeur, un bloc d’avis à copier-coller suffit. Si votre site est fait sur mesure, une clé API lui permet de récupérer les avis depuis son serveur et de les afficher dans sa propre page, avec les données structurées que Google sait lire. C’est Google qui décide ensuite d’afficher ou non les étoiles.

Pour qui : les sites sans module

De plus en plus de boutiques et de SaaS sont créés avec des outils d’IA comme Lovable, Bolt ou v0, souvent en Next.js, ou par un développeur. D’autres vendent sur Webflow, Wix, Podia ou Kajabi. Ces sites n’ont pas de module Avitime à installer, et c’est très bien : tout se fait depuis votre espace commerçant.

  • Vous n’avez pas de développeur : ajoutez vos produits à la main et collez le bloc d’avis dans votre page. Rien d’autre à faire.
  • Votre site est fait sur mesure (ou vous l’avez construit avec une IA qui écrit du code) : vous pouvez en plus afficher les avis dans le code de vos pages produits, avec une clé API.

Ajouter vos produits et lancer un test

  1. Dans votre espace commerçant, ouvrez « Ma boutique », section « Site sur mesure, Systeme.io ou autre plateforme », puis choisissez « Site sur mesure ou autre plateforme ».
  2. Indiquez le nom de votre marque et l’adresse de votre site, puis cliquez sur « Continuer ».
  3. Ajoutez chaque produit à faire tester : nom, description courte, prix public, page du produit et image. Chaque produit reçoit un n° API (1, 2, 3…), affiché à côté de son nom : c’est ce numéro que votre site utilisera pour récupérer ses avis.
  4. Dans « Campagnes », créez une campagne : produit physique ou numérique, centres d’intérêt visés, nombre de testeurs. Pour un produit numérique, indiquez comment le testeur y accède (lien d’inscription gratuite, code, crédits offerts).

C’est Avitime qui sélectionne les testeurs, jamais vous : c’est ce qui garantit des avis indépendants. En ce moment, vos 5 premiers tests sont offerts, sans abonnement.

Produit physique : vous expédiez vous-même

Sans module, aucune boutique ne reçoit la commande du testeur. Avitime vous la transmet directement :

  1. Le testeur sélectionné valide sa commande à 0 € depuis son espace Avitime. Il est prévenu que son nom, son adresse de livraison et son téléphone vous sont transmis pour l’expédition.
  2. Vous recevez un e-mail « Commande testeur à expédier ». Dans « Commandes testeurs », l’adresse du testeur s’affiche dans l’encadré « À expédier vous-même ».
  3. Vous expédiez le produit avec votre transporteur habituel, livraison offerte, puis vous cliquez sur « Marquer comme expédié » en indiquant le transporteur et le numéro de suivi. Le testeur voit le suivi dans son espace.
  4. À la réception, le testeur clique sur « J’ai bien reçu mon produit » : il a ensuite 21 jours pour publier son avis. S’il oublie de confirmer, vous pouvez cliquer sur « Marquer comme livré ».

L’adresse ne sert qu’à cette expédition : elle est effacée de la commande dès la livraison, et au plus tard 60 jours après la commande. Vous ne devez pas contacter le testeur au sujet de son avis.

Le bloc à copier-coller se trouve dans « Ma boutique », sous chaque produit : « Afficher les avis avec un code à copier (sans développeur) ». La suite de ce guide détaille la clé API.

Étape 1 : générer la clé API

  1. Dans « Ma boutique », sous votre site, ouvrez « Afficher les avis dans le code de votre site (clé API, étoiles Google) ».
  2. Cliquez sur « Générer ma clé API ». La clé commence par avt_. Copiez-la tout de suite : elle n’est affichée qu’une seule fois. Avitime n’en garde qu’une empreinte.
  3. Enregistrez-la dans les variables d’environnement de votre site, par exemple AVITIME_REVIEWS_KEY (sur Vercel : Settings → Environment Variables ; ailleurs : le fichier .env du serveur, jamais publié).

La clé ne donne accès qu’aux avis publiés de vos produits, en lecture seule : elle ne permet ni de modifier quoi que ce soit, ni de voir vos testeurs. Elle doit tout de même rester secrète, pour que personne ne l’utilise à votre place. Perdue ou exposée par erreur ? Cliquez sur « Générer une nouvelle clé API » : l’ancienne cesse aussitôt de fonctionner.

Étape 2 : appeler l’API depuis votre serveur

Votre site appelle cette adresse, avec le n° API du produit et la clé dans l’en-tête :

GET https://app.avitime.fr/api/v1/site/reviews/1
Authorization: Bearer avt_votre_cle

La réponse, en JSON, contient :

  • product : le n°, le nom, l’adresse et l’image du produit ;
  • count et average : le nombre d’avis et la note moyenne sur 5 ;
  • notice : la mention à afficher avec les avis, « Produit offert pour test — Testeur Avitime vérifié » ;
  • reviews : les avis publiés, du plus récent au plus ancien, avec la note (rating), le titre, le texte (body), les points forts et les points faibles (pros, cons), la date (published_at), le nom affiché du testeur (tester.display_name, par exemple « Julie B. »), les photos (media), la vidéo éventuelle (video) et votre réponse (merchant_reply) ;
  • jsonld : les données structurées schema.org (Product, note moyenne et avis), prêtes à mettre telles quelles dans une balise <script type="application/ld+json">.

Pour un logiciel, un SaaS ou une appli, ajoutez ?type=software à l’adresse : les données structurées utilisent alors le type SoftwareApplication au lieu de Product.

Trois règles pratiques :

  • Appelez l’API depuis le serveur, jamais depuis le navigateur : la clé serait visible de tous. L’API refuse d’ailleurs les appels directs d’une page web (pas d’en-têtes CORS).
  • Gardez la réponse en cache, une heure suffit : les avis ne changent pas à chaque visite. La limite est de 1 200 appels par heure.
  • Sans avis, la liste est vide et les données structurées ne contiennent pas de note : n’affichez rien, ou un message neutre.

Exemple complet avec Next.js

Dans une page produit écrite comme composant serveur (le cas par défaut avec l’App Router, et celui que génèrent la plupart des outils d’IA), la clé reste sur le serveur :

// app/produits/[slug]/page.tsx (composant serveur)
async function getAvis(numeroApi: number) {
  const res = await fetch(`https://app.avitime.fr/api/v1/site/reviews/${numeroApi}`, {
    headers: { Authorization: `Bearer ${process.env.AVITIME_REVIEWS_KEY}` },
    next: { revalidate: 3600 }, // mis en cache 1 heure
  });
  return res.ok ? res.json() : null;
}

export default async function PageProduit() {
  const avis = await getAvis(1); // le n° API du produit, affiché dans Avitime
  return (
    <main>
      {/* … votre fiche produit … */}
      {avis?.count ? (
        <section aria-label="Avis clients">
          <script type="application/ld+json"
            dangerouslySetInnerHTML={{ __html: JSON.stringify(avis.jsonld).replace(/</g, "\\u003c") }} />
          <h2>{avis.average}/5 · {avis.count} avis</h2>
          <p>{avis.notice}</p>
          {avis.reviews.map((r) => (
            <article key={r.id}>
              <p>{"★".repeat(r.rating)}{"☆".repeat(5 - r.rating)} {r.title}</p>
              <p>{r.body}</p>
              <p>{r.tester.display_name} · {r.published_at}</p>
              {r.merchant_reply ? <p>Réponse de la boutique : {r.merchant_reply.body}</p> : null}
            </article>
          ))}
        </section>
      ) : null}
    </main>
  );
}

Le .replace(/</g, "\\u003c") empêche qu’un texte d’avis contenant </script> ne casse la page : gardez-le. Le reste (titres, textes) est affiché par React, qui protège déjà le contenu.

Vous utilisez Lovable ou Bolt ? Vous pouvez donner ce guide à l’outil en lui demandant d’ajouter les avis Avitime à vos pages produits, côté serveur, avec la clé dans une variable d’environnement. Vérifiez ensuite que la clé n’apparaît nulle part dans le code envoyé au navigateur.

Exemple en PHP ou avec curl

Pour tester la clé depuis un terminal :

curl -H "Authorization: Bearer avt_votre_cle" \
  https://app.avitime.fr/api/v1/site/reviews/1

En PHP, sur n’importe quel site :

<?php
$ctx = stream_context_create(['http' => [
  'header' => 'Authorization: Bearer ' . getenv('AVITIME_REVIEWS_KEY'),
]]);
$avis = json_decode(@file_get_contents('https://app.avitime.fr/api/v1/site/reviews/1', false, $ctx), true);
if ($avis && $avis['count'] > 0) {
  echo '<script type="application/ld+json">' . json_encode($avis['jsonld'], JSON_UNESCAPED_UNICODE | JSON_HEX_TAG) . '</script>';
  echo '<p>' . htmlspecialchars($avis['notice']) . '</p>';
  foreach ($avis['reviews'] as $r) {
    echo '<article><b>' . (int) $r['rating'] . '/5 ' . htmlspecialchars($r['title']) . '</b><p>'
       . htmlspecialchars($r['body']) . '</p><small>' . htmlspecialchars($r['tester']['display_name']) . '</small></article>';
  }
}

Pensez à mettre la réponse en cache (fichier, base de données ou cache de votre hébergeur) plutôt que d’appeler l’API à chaque visite.

Étoiles Google : ce qu’il faut respecter

Les données structurées fournies par Avitime suivent le format que Google décrit pour les extraits d’avis (Product ou SoftwareApplication, AggregateRating, Review). Pour qu’elles soient prises en compte :

  • Les avis doivent être visibles sur la page, pas seulement dans les données structurées. Google ignore, voire sanctionne, des notes que le visiteur ne voit pas.
  • Une seule source de note par produit : si votre page contient déjà une note issue d’un autre outil d’avis, n’en ajoutez pas une deuxième sur le même produit.
  • Affichez la mention « Produit offert pour test » : la loi impose d’indiquer qu’un avis a été donné en échange d’un produit offert. Le champ notice vous la donne.
  • N’ajoutez jamais d’avis inventés et n’en retirez aucun : tous les avis sont publiés, positifs comme négatifs. Vous pouvez répondre publiquement à chacun depuis votre espace.

Même avec des données parfaites, c’est Google qui décide d’afficher ou non les étoiles dans ses résultats, et quand. Avitime ne peut rien promettre sur ce point : les données structurées lui donnent simplement ce qu’il demande. Vous pouvez vérifier votre page avec le test des résultats enrichis de Google (lien dans les sources).

Questions fréquentes

Mon site a été créé avec Lovable ou Bolt : puis-je utiliser Avitime ?

Oui. Choisissez « Site sur mesure ou autre plateforme » dans « Ma boutique », ajoutez vos produits à la main, puis lancez une campagne. Pour afficher les avis, collez le bloc d’avis ou générez une clé API et demandez à l’outil d’IA de l’intégrer côté serveur.

Faut-il un développeur ?

Non pour faire tester vos produits et afficher les avis avec le bloc à copier-coller. La clé API, elle, demande d’écrire quelques lignes de code dans votre site, ou de demander à votre développeur ou à votre outil d’IA de le faire.

Puis-je faire tester des produits physiques sans boutique PrestaShop, WooCommerce ou Shopify ?

Oui. Quand un testeur sélectionné valide sa commande à 0 €, son nom, son adresse et son téléphone s’affichent dans « Commandes testeurs ». Vous expédiez le produit vous-même, vous indiquez le suivi, et l’adresse est effacée dès la livraison.

La clé API est-elle dangereuse si elle fuite ?

Elle ne donne accès qu’aux avis publiés de vos produits, en lecture seule. Elle doit tout de même rester secrète. En cas de doute, générez-en une nouvelle : l’ancienne cesse aussitôt de fonctionner.

Les étoiles apparaîtront-elles dans Google ?

Peut-être, mais personne ne peut le garantir : c’est Google qui décide. Avitime vous donne des données structurées conformes à ses consignes, et des avis vérifiés ; à vous de les afficher visiblement sur la page du produit.

Combien coûte la clé API ?

Rien de plus : elle fait partie de votre espace commerçant. En ce moment, vos 5 premiers tests sont offerts, sans abonnement.
