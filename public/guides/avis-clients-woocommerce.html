Avis clients sur WooCommerce : les bons réglages et les avis vérifiés

WooCommerce gère les avis clients sans extension, avec une option précieuse : le badge « propriétaire vérifié ». Voici les bons réglages, et comment passer de zéro avis à vos premiers retours clients.

Cyril Quémy, fondateur d’Avitime
Publié le 15 octobre 2026 · lecture 5 min

Au sommaire

  1. Les réglages natifs
  2. Nos recommandations
  3. Modérer sans trier
  4. Obtenir vos premiers avis
  5. Avitime sur WooCommerce

L’essentiel : activez le badge « propriétaire vérifié » et la note obligatoire. Vos avis gagnent en crédibilité, et vous pouvez dire précisément comment ils sont contrôlés, comme la loi le demande.

1. Les réglages natifs

Dans WooCommerce → Réglages → Produits, rubrique Avis, cinq options :

  • Activer les avis produits ;
  • Afficher le libellé « propriétaire vérifié » sur les avis des clients qui ont acheté le produit ;
  • Réserver les avis aux « propriétaires vérifiés » ;
  • Activer la note par étoiles ;
  • Rendre la note obligatoire.

2. Nos recommandations

  • Activez le libellé « propriétaire vérifié » : c’est une preuve simple et visible que l’avis vient d’un acheteur.
  • Rendez la note obligatoire : une note moyenne n’a de sens que si chaque avis en a une.
  • Réserver les avis aux acheteurs protège contre les avis fantaisistes, mais réduit le volume. Au lancement, quand vous avez peu de ventes, c’est un choix à peser.
  • Indiquez sur votre site comment vos avis sont contrôlés : c’est une obligation légale (voir Faux avis en ligne : ce que dit la loi).

3. Modérer sans trier

Les avis se gèrent dans Produits → Avis : approuver, répondre, marquer comme indésirable. Modérez pour écarter le spam, les insultes ou les données personnelles, jamais pour masquer un avis critique authentique. Une critique bien traitée rassure davantage qu’une page sans défaut (voir Répondre aux avis négatifs).

4. Obtenir vos premiers avis

WooCommerce n’envoie pas de demande d’avis après l’achat. Prévoyez un e-mail quelques jours après la livraison, avec un lien direct vers la fiche produit. Pour amorcer les premiers avis quand les ventes sont encore rares, voir Comment obtenir ses premiers avis clients et Combien d’avis faut-il pour vendre ?

5. Avitime sur WooCommerce

Avitime a une extension WordPress pour WooCommerce (WooCommerce 7 et plus, compatible HPOS et paiement en blocs), disponible dans l’annuaire officiel des extensions WordPress : Avitime – Tester reviews for WooCommerce (dans votre administration : Extensions → Ajouter, puis « Avitime »). La commande du testeur arrive « En cours » à 0 € avec la mention « ★ Testeur Avitime », un encadré vous permet de saisir le suivi, et l’avis est publié avec la mention « Produit offert pour test — Testeur Avitime vérifié ». Voir l’offre commerçants.

6. Questions fréquentes

Faut-il un plugin d’avis pour WooCommerce ?

Pas pour commencer : WooCommerce gère les avis et le libellé « propriétaire vérifié » sans extension. Un plugin d’avis devient utile pour envoyer automatiquement des demandes d’avis après la livraison, ajouter des photos ou afficher les avis ailleurs sur le site (voir bien choisir son widget d’avis). Pour obtenir vos premiers avis quand les ventes sont encore rares, l’extension Avitime fait tester vos produits.

Existe-t-il un plugin d’avis gratuit pour WooCommerce ?

Oui : les avis natifs sont gratuits, et l’annuaire WordPress.org propose plusieurs extensions d’avis gratuites ou en version de base gratuite. L’extension Avitime s’y télécharge gratuitement ; le service Avitime lui-même fonctionne sur abonnement, après vos 5 premiers tests offerts.

Comment installer l’extension Avitime sur WooCommerce ?

Dans WordPress : Extensions → Ajouter, cherchez « Avitime », installez et activez l’extension, puis cliquez sur « Connecter à Avitime ». Le détail : intégrations.
