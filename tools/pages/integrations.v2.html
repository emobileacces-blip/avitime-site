Module d’avis clients pour PrestaShop, WooCommerce et Shopify

Avitime se branche sur votre boutique avec un module dédié à chaque plateforme. Installé en quelques minutes, sans une ligne de code : vous gardez vos produits, vos transporteurs et vos habitudes. Votre site est ailleurs ? Avitime fonctionne aussi avec Systeme.io et avec tout site sur mesure ou autre plateforme (Lovable, Bolt, Next.js, Webflow, Wix…), sans module.

Ce que fait le module, sur chaque plateforme

  • Catalogue synchronisé automatiquement : produits, variantes, stocks et images. Vous choisissez dans Avitime le produit à faire tester.
  • Commandes testeurs à 0 € créées dans votre back-office, comme une commande normale, et clairement repérées comme commandes Avitime.
  • Commande vérifiée côté serveur : lien à usage unique lié au testeur, au produit et à la mission, remise de 100 % et livraison offerte réservées à ce testeur, total final contrôlé à 0 €.
  • Suivi d’expédition transmis à Avitime et au testeur : le délai de test démarre à la livraison.
  • Avis vérifiés affichés sur vos fiches produits, avec la mention « Produit offert pour test — Testeur Avitime vérifié », et les étoiles dans un format que Google sait lire.

Module PrestaShop

Chaque commande testeur arrive avec l’état « Testeur Avitime », le paiement « Avitime – produit offert » et un bandeau sur la fiche commande. Une colonne et un filtre « Avitime » les retrouvent dans la liste des commandes. L’expédition, la livraison, l’annulation, le remboursement et le numéro de suivi sont transmis à Avitime. Une page de diagnostic vérifie la connexion.

  1. Téléchargez le module depuis votre espace commerçant (Ma boutique).
  2. Dans votre back-office PrestaShop : Modules → Gestionnaire de modules → Téléverser un module.
  3. Cliquez sur « Connecter à Avitime ». Comptez environ cinq minutes.

Extension WooCommerce

La commande testeur est créée « En cours » à 0 €, avec la mention « ★ Testeur Avitime » dans la liste des commandes et un encadré Avitime pour saisir le suivi.

  1. Dans WordPress : Extensions → Ajouter, puis cherchez « Avitime ».
  2. Installez et activez l’extension.
  3. Cliquez sur « Connecter à Avitime » : votre catalogue se synchronise.

Application Shopify

L’application s’ouvre dans l’administration Shopify. Les commandes testeurs sont des commandes Shopify normales à 0 €, étiquetées « avitime », et le bloc d’avis s’ajoute à votre thème en un clic. L’abonnement est réglé par la facturation Shopify.

L’application est en cours de validation par Shopify et sera bientôt sur le Shopify App Store. Vous êtes sur Shopify ? Écrivez-nous pour être prévenu dès sa sortie. Le pas-à-pas : avis clients sur Shopify, et les applications d’avis gratuites : avis sur Shopify sans application payante.

Systeme.io

Pour une formation vendue sur Systeme.io, il n’y a ni module ni catalogue à synchroniser : dans votre espace commerçant, rubrique « Ma boutique », section « Site sur mesure, Systeme.io ou autre plateforme », collez votre clé API (Systeme.io → Paramètres → Clés API publiques) puis choisissez la formation. Avitime inscrit chaque testeur sélectionné à la formation, avec son accord, et Systeme.io lui envoie ses identifiants. Le test est un test de produit numérique : une durée d’utilisation avant l’avis, et une vidéo d’utilisation demandée au testeur. Les avis s’affichent avec un bloc à copier-coller dans un bloc « code HTML » de votre page de vente.

Site sur mesure ou autre plateforme

Votre site a été créé avec Lovable, Bolt ou Next.js, par un développeur, ou sur Webflow, Wix, Podia, Kajabi, LearnyBox ? Pas besoin d’attendre un module : choisissez « Site sur mesure ou autre plateforme » dans « Ma boutique » et ajoutez vos produits à la main (nom, prix public, page du produit, image). Physiques ou numériques, ils se testent tous.

  1. Produit physique : quand un testeur sélectionné valide sa commande à 0 €, son nom, son adresse de livraison et son téléphone s’affichent dans « Commandes testeurs ». Vous expédiez le produit vous-même, puis vous cliquez sur « Marquer comme expédié » en indiquant le numéro de suivi. Le testeur confirme la réception : il a ensuite 21 jours pour publier son avis. L’adresse est effacée de la commande dès la livraison (au plus tard 60 jours après la commande).
  2. Produit numérique : vous indiquez dans la campagne comment le testeur y accède (lien d’inscription gratuite, code, crédits offerts). Il retrouve ces consignes dans son espace dès sa commande à 0 €.
  3. Les avis, sans développeur : un bloc d’avis à copier-coller dans un bloc « code HTML » de votre page. Simple, mais Google ne compte pas ces avis comme faisant partie de votre page.
  4. Les avis, avec une clé API : dans « Ma boutique », cliquez sur « Générer ma clé API ». Votre site récupère les avis de chaque produit depuis son serveur et les affiche dans sa propre page, avec les données structurées (Product, note moyenne, avis) que Google sait lire. C’est Google qui décide d’afficher ou non les étoiles.

Questions fréquentes

Faut-il un développeur ?

Non. L’installation se fait depuis votre back-office, puis un bouton « Connecter à Avitime » relie la boutique. Aucune ligne de code n’est à écrire. Seule la clé API, facultative, sert aux sites sur mesure qui veulent afficher les avis dans leur propre code.

Le module modifie-t-il mes prix ou mes commandes clients ?

Non. La remise de 100 % et la livraison offerte ne s’appliquent qu’à la commande du testeur sélectionné, par un lien à usage unique. Vos clients ne voient aucun changement.

Puis-je désinstaller le module ?

Oui, à tout moment, comme n’importe quel module ou extension. Pensez d’abord à terminer vos campagnes en cours pour que les testeurs puissent publier leur avis.

Qui expédie les produits ?

Votre boutique, avec ses transporteurs habituels. Avitime ne stocke ni n’expédie de produits. Le dropshipping est accepté. Sur un site sur mesure, vous expédiez vous-même à l’adresse affichée dans « Commandes testeurs », puis vous indiquez le suivi.

Mon site n’est ni sur PrestaShop, ni sur WooCommerce, ni sur Shopify : puis-je utiliser Avitime ?

Oui. Choisissez « Site sur mesure ou autre plateforme » dans « Ma boutique » et ajoutez vos produits à la main : ça marche avec un site créé avec Lovable, Bolt ou Next.js, Webflow, Wix, Podia, Kajabi… Pour afficher les avis, copiez le bloc d’avis, ou générez une clé API si votre site est fait sur mesure.
